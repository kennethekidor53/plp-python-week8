# My Python Toolkit

## Project Description

My Python Toolkit is a simple program that contains four useful tools. It uses a menu that allows users to choose which tool they want to use.

The toolkit includes:

1. **Number Guessing Game:** The computer chooses a secret number, and the user tries to guess it.
2. **To-Do List:** Allows users to add tasks, view tasks, and mark tasks as complete.
3. **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
4. **Countdown Timer:** Counts down from the number of seconds entered by the user.

## How to Run the Program

Follow these steps to run the toolkit:

1. Make sure Python is installed on your computer.
2. Save the Python program as `toolkit.py`.
3. Open your terminal or command prompt.
4. Navigate to the folder containing the file.
5. Type the following command:

```bash
python toolkit.py
```

6. Press Enter.
7. The menu will appear. Choose a number from 1 to 5 to use a tool or quit the program.

## Reflection

The hardest part of this project was creating the menu loop so that the program could return to the main menu after using each tool. The part that took the longest to fix was handling invalid user input without making the program crash. I learned how to use while loops, if statements, elif statements, and else statements. I also learned how to use functions to organize my code and make the program easier to understand. I enjoyed creating the number guessing game because it was interesting to make the computer choose a random number. If I had one more week, I would add more tools such as a name formatter, a currency converter, and a stopwatch. I would also improve the design of the menu to make the toolkit more attractive and user-friendly.
