TOOLKIT PLAN

1. Number Guessing Game
The program chooses a secret number and lets the player guess until they get it right.
Concepts: loop (repeat guesses), conditional (check too high, too low, or correct), random number, integer input, f-string (show the guess count).

2. To-Do List
The program lets the user add tasks, view all tasks, and mark tasks as complete.
Concepts: list (store tasks), loop (keep showing the menu), conditional (choose an action), f-string (display task numbers and statuses).

3. Simple Calculator
The program asks for two numbers and an operation, then displays the result.
Concepts: input, type conversion (float), conditional (choose addition, subtraction, multiplication, or division), arithmetic operators, f-string (format the result).

4. Countdown Timer
The program counts down from a number of seconds entered by the user and then displays a message.
Concepts: loop (count down), conditional (check for valid input), integer conversion, time delay, f-string (display the remaining seconds).
